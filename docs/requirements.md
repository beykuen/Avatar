# 需求文件：網頁版紙娃娃貼圖產生器

## 1. 專案目標

提供一個網頁版紙娃娃遊戲，讓使用者自行設計人偶、搭配衣服與配件、選擇場景並加上文字，最後輸出為一張表情貼圖（PNG 圖片）。使用者只需用瀏覽器開啟網址即可操作。

## 2. 前提假設

- 「網頁直接可在 GitHub 上操作」解讀為：部署在 GitHub Pages，使用者用瀏覽器開啟網址即可使用，不需安裝、不需後端伺服器。
- 所有素材（人偶部件、衣服、配件、場景）由專案內建提供，使用者只能從內建選項中挑選。
- 目標使用者為一般大眾，支援桌機瀏覽器與 iPad（觸控操作，Safari）；手機瀏覽器為次要（可操作即可）。
- 素材風格定為「Q 版可愛」：人偶為大頭小身的 Q 版比例，造型圓潤、可愛。
- 「表情貼圖」指單張靜態圖片，用於通訊軟體分享，不含動畫。
- 本版本為最小可用版本（MVP），不追求素材數量與進階編輯功能。

## 3. 功能清單

### F1 人偶基本設計
使用者可自訂人偶的下列外觀項目，並即時預覽：
- 膚色
- 髮型
- 髮色
- 臉部表情（例如開心、生氣、哭泣、驚訝等）

### F2 衣服
使用者可為人偶選擇衣服，分為「上衣」與「下著」兩類，每類可選擇「無」或其中一款，且可切換。

### F3 配件
使用者可為人偶加上配件，配件分為「帽子/頭飾」、「眼鏡/臉部飾品」、「手持物或其他飾品」三類，每類可選擇「無」或其中一款；不同類別的配件可同時佩戴。

### F4 場景選擇
使用者可選擇人偶所處的背景場景，且可選擇「純色背景」或「透明背景」。

### F5 文字輸入
使用者可輸入一段短文字，文字會顯示在貼圖畫面上；使用者可選擇文字顏色，並可選擇文字位置為「上方」或「下方」。

### F6 即時預覽
任何設計變更（F1～F5、F10）都應即時反映在畫面預覽上，預覽內容與最終輸出的貼圖一致。

### F7 輸出貼圖
使用者可將目前畫面輸出並下載為一張貼圖圖片檔。

### F8 隨機與重設
提供「隨機搭配」與「全部重設」功能（已確認保留），方便快速開始。

### F10 交通工具或其他設施
除配件外，使用者可為人偶選擇一項「交通工具或其他設施」（例如腳踏車、滑板、汽車、氣球），可選擇「無」或其中一款，且可切換；此類別獨立於 F3 的配件，可與配件同時顯示。

### F9 GitHub Pages 可用
網頁可部署於 GitHub Pages，使用者以瀏覽器開啟公開網址即可完整使用 F1～F8、F10 所有功能，不需登入、不需安裝、不需自建伺服器。

## 4. 驗收條件

| 編號 | 對應功能 | 驗收條件 |
|---|---|---|
| AC1 | F1 | 膚色至少提供 5 種選項；髮型至少 5 種；髮色至少 6 種；臉部表情至少 5 種。每項選擇後預覽立即改變。 |
| AC2 | F2 | 上衣至少 5 款（不含「無」）、下著至少 4 款（不含「無」）；每類皆可選「無」；切換後預覽立即改變，且更換一款時前一款不會殘留於畫面。 |
| AC3 | F3 | 「帽子/頭飾」至少 4 款、「眼鏡/臉部飾品」至少 3 款、「手持物或其他飾品」至少 3 款（皆不含「無」）；每類皆可選「無」；三類配件可同時顯示，彼此不互相取代。 |
| AC4 | F4 | 場景至少提供 6 種（含至少 1 種純色背景）；另可切換為「透明背景」；選擇後預覽立即改變。 |
| AC5 | F5 | 可輸入至少 10 個中文字或英文字元的文字（已確認：至少 10 字）；文字顯示於貼圖畫面；至少提供 6 種文字顏色；可切換上方/下方位置；輸入空白時畫面不顯示文字。支援中文與英文輸入顯示正常、無亂碼。 |
| AC6 | F6 | 對 F1～F5、F10 的任一項變更，預覽區在 1 秒內更新；預覽畫面與下載的貼圖在人偶、衣服、配件、交通工具/設施、場景、文字的內容與相對位置上一致。 |
| AC7 | F7 | 點擊輸出按鈕後下載一個副檔名為 .png 的檔案；檔案為有效 PNG 圖片，可被一般圖片檢視器正常開啟；圖片尺寸為 370 × 320 像素（LINE 貼圖規格）；選擇透明背景時，輸出 PNG 的背景區域為透明（具 alpha 通道），選擇場景或純色背景時背景為不透明。 |
| AC8 | F7 | 輸出檔內容完整包含人偶、所選衣服與配件、所選交通工具/設施、所選場景與輸入文字，且人偶與文字未被裁切超出畫面邊界。 |
| AC9 | F8 | 點擊「隨機搭配」後，F1～F4、F10 各項目皆被隨機選擇一個有效選項（文字內容不被改動）；點擊「全部重設」後，所有選項回到預設值且文字清空。 |
| AC10 | F9 | 專案可在 GitHub Pages 以 https 公開網址開啟；於最新版 Chrome、Firefox、Edge 或 Safari（至少三種）開啟後，F1～F8、F10 全數可正常運作；整個使用過程不需登入、不需任何後端服務。 |
| AC11 | F9 | 首次載入頁面時，在一般寬頻網路下 5 秒內可看到可操作的介面與預設人偶。 |
| AC12 | 全部 | 在 1280 × 720 桌機視窗下，所有功能不需橫向捲動即可操作；在寬度 375 像素的手機視窗下，所有功能仍可使用（允許垂直捲動）。 |
| AC13 | F10 | 「交通工具或其他設施」至少 4 款（不含「無」），須含腳踏車、滑板、汽車、氣球或同等性質的選項；可選「無」；切換後預覽立即改變，且更換一款時前一款不會殘留於畫面；可與 F3 三類配件同時顯示，彼此不互相取代；輸出的貼圖中包含所選項目且未被裁切。 |
| AC14 | 全部（iPad） | 在 iPad Safari 以觸控（不使用滑鼠與實體鍵盤快捷鍵）可完成 F1～F8、F10 全部功能，包含文字輸入與輸出/下載貼圖；所有可點選的按鈕與選項觸控目標不小於 44 × 44 像素；操作不依賴滑鼠懸停（hover）。 |
| AC15 | 全部（iPad） | 在 iPad Safari 直式與橫式兩種方向下，皆可不需橫向捲動完成完整流程（挑選選項、輸入文字、預覽、輸出貼圖）；旋轉裝置後已選設計不遺失。 |
| AC16 | F7（iPad） | 在 iPad Safari 點擊輸出後，使用者可取得 370 × 320 的 PNG 貼圖（下載至「檔案」，或於 Safari 中開啟後可長按儲存至相簿），其內容與預覽一致。 |
| AC17 | 素材風格 | 所有人偶、衣服、配件、交通工具/設施、場景素材皆為 Q 版可愛風格：人偶為大頭小身的 Q 版比例（頭部高度約佔全身 1/3 以上）、輪廓圓潤、臉部五官簡化；各類素材風格一致、無寫實或不同畫風混用。 |

## 5. 不做的範圍

- 帳號系統、登入、註冊
- 後端伺服器、資料庫、雲端儲存
- 多人協作、分享連結、社群功能、線上圖庫
- 上傳使用者自訂圖片（自製衣服、背景、人偶部件）
- 動態貼圖（GIF、APNG、動畫）
- 多張貼圖批次輸出、貼圖包整合打包
- 儲存/載入設計存檔（重新整理頁面後設計不保留）
- 復原/重做（Undo/Redo）、圖層拖曳、自由縮放或旋轉部件
- 自訂字型上傳、文字特效（描邊、陰影等）、多段文字
- 直接上傳至 LINE、Telegram 等平台
- 多語系介面（僅提供繁體中文介面）
- 無障礙完整規範（WCAG 認證）
- 針對 iPad 以外手機的完整觸控最佳化（手機僅需可操作，見 AC12）

## 6. 已確認事項

以下事項已由使用者確認，並已反映於前提假設、功能清單與驗收條件：

1. **素材風格**：Q 版可愛（見前提假設、AC17）。
2. **支援裝置**：iPad 必須可用觸控完成所有功能，含輸出/下載貼圖（見 AC14～AC16）；桌機仍支援（AC12）。
3. **介面語言**：只做繁體中文。
4. **新增需求**：除配件外，增加「交通工具或其他設施」類別（見 F10、AC13，至少 4 款，可選「無」）。
5. **F6 即時預覽、F8 隨機／重設**：保留。
6. **其餘照原假設定案**：貼圖尺寸 370 × 320；提供透明背景 PNG 選項；選項數量維持原值（膚色 5、髮型 5、髮色 6、表情 5、上衣 5、下著 4、帽子 4、眼鏡 3、手持物 3、場景 6）；文字至少 10 字；文字樣式為 6 色加上下位置；部署只需能在 GitHub Pages 公開網址運作。
