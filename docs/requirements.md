# 需求文件：網頁版紙娃娃貼圖產生器

## 1. 專案目標

提供一個網頁版紙娃娃遊戲，讓使用者自行設計人偶、搭配衣服與配件、選擇場景並加上文字，最後輸出為一張表情貼圖（PNG 圖片）。使用者只需用瀏覽器開啟網址即可操作。

## 2. 前提假設

- 「網頁直接可在 GitHub 上操作」解讀為：部署在 GitHub Pages，使用者用瀏覽器開啟網址即可使用，不需安裝、不需後端伺服器。
- 所有素材（人偶部件、衣服、配件、場景）由專案內建提供，使用者只能從內建選項中挑選。
- 目標使用者為一般大眾，以桌機瀏覽器為主要使用環境，手機瀏覽器為次要（可操作即可）。
- 「表情貼圖」指單張靜態圖片，用於通訊軟體分享，不含動畫。
- 本版本為最小可用版本（MVP），不追求素材數量與進階編輯功能。

## 3. 功能清單

### F1 人偶基本設計
使用者可自訂人偶的下列外觀項目，並即時預覽：
- 膚色
- 髮型
- 髮色
- 臉部表情（例如開心、生氣、哭泣、驚訝等）

### F2 衣服
使用者可為人偶選擇衣服，分為「上衣」與「下著」兩類，每類可選擇「無」或其中一款，且可切換。

### F3 配件
使用者可為人偶加上配件，配件分為「帽子/頭飾」、「眼鏡/臉部飾品」、「手持物或其他飾品」三類，每類可選擇「無」或其中一款；不同類別的配件可同時佩戴。

### F4 場景選擇
使用者可選擇人偶所處的背景場景，且可選擇「純色背景」或「透明背景」。

### F5 文字輸入
使用者可輸入一段短文字，文字會顯示在貼圖畫面上；使用者可選擇文字顏色，並可選擇文字位置為「上方」或「下方」。

### F6 即時預覽
任何設計變更（F1～F5）都應即時反映在畫面預覽上，預覽內容與最終輸出的貼圖一致。

### F7 輸出貼圖
使用者可將目前畫面輸出並下載為一張貼圖圖片檔。

### F8 隨機與重設
提供「隨機搭配」與「全部重設」功能，方便快速開始。

### F9 GitHub Pages 可用
網頁可部署於 GitHub Pages，使用者以瀏覽器開啟公開網址即可完整使用 F1～F8 所有功能，不需登入、不需安裝、不需自建伺服器。

## 4. 驗收條件

| 編號 | 對應功能 | 驗收條件 |
|---|---|---|
| AC1 | F1 | 膚色至少提供 5 種選項；髮型至少 5 種；髮色至少 6 種；臉部表情至少 5 種。每項選擇後預覽立即改變。 |
| AC2 | F2 | 上衣至少 5 款（不含「無」）、下著至少 4 款（不含「無」）；每類皆可選「無」；切換後預覽立即改變，且更換一款時前一款不會殘留於畫面。 |
| AC3 | F3 | 「帽子/頭飾」至少 4 款、「眼鏡/臉部飾品」至少 3 款、「手持物或其他飾品」至少 3 款（皆不含「無」）；每類皆可選「無」；三類配件可同時顯示，彼此不互相取代。 |
| AC4 | F4 | 場景至少提供 6 種（含至少 1 種純色背景）；另可切換為「透明背景」；選擇後預覽立即改變。 |
| AC5 | F5 | 可輸入至少 10 個中文字或英文字元的文字（上限不低於 10 字，上限值由使用者確認）；文字顯示於貼圖畫面；至少提供 6 種文字顏色；可切換上方/下方位置；輸入空白時畫面不顯示文字。支援中文與英文輸入顯示正常、無亂碼。 |
| AC6 | F6 | 對 F1～F5 的任一項變更，預覽區在 1 秒內更新；預覽畫面與下載的貼圖在人偶、衣服、配件、場景、文字的內容與相對位置上一致。 |
| AC7 | F7 | 點擊輸出按鈕後下載一個副檔名為 .png 的檔案；檔案為有效 PNG 圖片，可被一般圖片檢視器正常開啟；圖片尺寸為 370 × 320 像素（LINE 貼圖規格）；選擇透明背景時，輸出 PNG 的背景區域為透明（具 alpha 通道），選擇場景或純色背景時背景為不透明。 |
| AC8 | F7 | 輸出檔內容完整包含人偶、所選衣服與配件、所選場景與輸入文字，且人偶與文字未被裁切超出畫面邊界。 |
| AC9 | F8 | 點擊「隨機搭配」後，F1～F4 各項目皆被隨機選擇一個有效選項（文字內容不被改動）；點擊「全部重設」後，所有選項回到預設值且文字清空。 |
| AC10 | F9 | 專案可在 GitHub Pages 以 https 公開網址開啟；於最新版 Chrome、Firefox、Edge 或 Safari（至少三種）開啟後，F1～F8 全數可正常運作；整個使用過程不需登入、不需任何後端服務。 |
| AC11 | F9 | 首次載入頁面時，在一般寬頻網路下 5 秒內可看到可操作的介面與預設人偶。 |
| AC12 | 全部 | 在 1280 × 720 桌機視窗下，所有功能不需橫向捲動即可操作；在寬度 375 像素的手機視窗下，所有功能仍可使用（允許垂直捲動）。 |

## 5. 不做的範圍

- 帳號系統、登入、註冊
- 後端伺服器、資料庫、雲端儲存
- 多人協作、分享連結、社群功能、線上圖庫
- 上傳使用者自訂圖片（自製衣服、背景、人偶部件）
- 動態貼圖（GIF、APNG、動畫）
- 多張貼圖批次輸出、貼圖包整合打包
- 儲存/載入設計存檔（重新整理頁面後設計不保留）
- 復原/重做（Undo/Redo）、圖層拖曳、自由縮放或旋轉部件
- 自訂字型上傳、文字特效（描邊、陰影等）、多段文字
- 直接上傳至 LINE、Telegram 等平台
- 多語系介面（僅提供繁體中文介面）
- 無障礙完整規範（WCAG 認證）

## 6. 待使用者確認事項

1. **貼圖尺寸**：假設為 370 × 320 像素（LINE 貼圖規格）。是否採用？或改為正方形（如 512 × 512，Telegram/WhatsApp 常見）？
2. **透明背景**：假設提供「透明背景」選項，輸出為具透明通道的 PNG。是否需要？
3. **選項數量**：驗收條件中的最低數量（例如膚色 5、髮型 5、髮色 6、表情 5、上衣 5、下著 4、帽子 4、眼鏡 3、手持物 3、場景 6）是否合適？是否需調高或調低？
4. **文字長度上限**：假設至少可輸入 10 字，是否有指定的上限（例如 10 字或 15 字）？
5. **文字樣式**：假設僅提供顏色（6 色）與上下位置選擇。是否需要額外的字型選擇或描邊效果？
6. **素材風格與來源**：人偶風格（可愛 Q 版、簡約扁平等）未指定。素材由專案自行繪製／產生，是否有指定風格偏好或需使用特定授權素材？
7. **隨機/重設功能（F8）**：此為我額外加入的便利功能，是否保留？
8. **支援裝置**：假設以桌機瀏覽器為主、手機可用即可。是否需要針對手機觸控做更完整的最佳化？
9. **介面語言**：假設僅繁體中文介面，是否同意？
10. **GitHub Pages 部署範圍**：假設只需「能在 GitHub Pages 公開網址上運作」，部署設定（如自動部署）屬於設計階段決定，是否同意？
